# Linux System Monitor

A TCP client–server system monitor written in C for Linux.
The server forks **one child process per connection** (no threads), answers
a one-line ASCII protocol (`PING`, `GET ALL|CPU|MEMORY|UPTIME|HOSTNAME`,
`QUIT`, `DEMO WAIT N`), shares its network / protocol / logging code with
the client through a dynamic library `libcommon.so`, supports a two-stage
DEBUG log (compile-time + run-time), and ships a reproducible *baseline*
build for before/after robustness experiments.

Full requirements: [`SPEC.md`](SPEC.md). Test report with evidence:
[`docs/REPORT.md`](docs/REPORT.md).

## Layout

```text
include/        common.h net.h protocol.h logger.h system_info.h
src/common/     net.c protocol.c logger.c          -> build/lib/libcommon.so
src/server/     server.c request_handler.c system_info.c -> build/bin/server
src/client/     client.c                           -> build/bin/client
tests/          test_protocol.sh concurrent_10.sh test_robustness.sh
                debug_matrix.sh capture_pcap.sh common.sh
docs/           REPORT.md, evidence/ (generated logs), screenshots/
captures/       loopback.pcap (generated by tests/capture_pcap.sh)
```

## Requirements

Ubuntu 18.04 or newer (tested on Ubuntu 18.04.6, kernel 5.4, GCC 7.5):

```bash
sudo apt-get install -y build-essential tcpdump
```

## Build

| Command | Result |
| --- | --- |
| `make` | robust build, `DEBUG=0` → `build/release/`, published to `build/bin/{server,client}` and `build/lib/libcommon.so` |
| `make DEBUG=1` | robust build with DEBUG log compiled in → `build/debug/`, published to `build/bin`, `build/lib` |
| `make baseline` | unprotected experiment build (`-DBASELINE_MODE=1`) → `build/baseline/{bin,lib}` only; `build/bin` is untouched |
| `make test` | `make` + `tests/test_protocol.sh` + `tests/concurrent_10.sh` |
| `make clean` | remove `build/` |

Every mode compiles into its own directory (`build/release`, `build/debug`,
`build/baseline`), so switching `DEBUG` never reuses stale object files.
`build/bin` and `build/lib` always contain a copy of the **last**
`make` / `make DEBUG=1` output.

Compiler flags: `-std=c11 -Wall -Wextra -Werror -D_POSIX_C_SOURCE=200809L
-D_DEFAULT_SOURCE`. The library is built with `-fPIC -shared`; both
executables link with `-lcommon` and carry `RUNPATH=$ORIGIN/../lib`, so they
run from any working directory without `LD_LIBRARY_PATH`. If you move a
binary elsewhere, set `LD_LIBRARY_PATH=/path/to/build/lib`.

Verify the dynamic link:

```bash
ldd build/bin/server | grep libcommon
ldd build/bin/client | grep libcommon
```

## Run

```bash
# Server (defaults: 127.0.0.1:9090)
./build/bin/server --host 127.0.0.1 --port 9090 [--debug] [--demo]

# Client: single command
./build/bin/client --host 127.0.0.1 --port 9090 --command "GET ALL"

# Client: interactive (reads commands from stdin)
./build/bin/client --port 9090

# Keep the connection open 5 s after the reply (concurrency demos)
./build/bin/client --command "GET ALL" --hold 5

# Connect and send nothing for 15 s (timeout test); exclusive with --command/--hold
./build/bin/client --idle 15
```

Client exit codes: `0` OK, `1` server answered `ERR`, `2` usage error,
`3` connection / transport error.

### Debug logging (two stages)

| Build | Flag | `[DEBUG]` lines |
| --- | --- | --- |
| `make` (`DEBUG=0`) | none | no |
| `make` (`DEBUG=0`) | `--debug` | no – not compiled in |
| `make DEBUG=1` | none | no |
| `make DEBUG=1` | `--debug` | **yes** |

`INFO` and `ERROR` lines are always printed. Log format:
`[YYYY-MM-DD HH:MM:SS] [LEVEL] [pid=N] message` on stderr.

## Protocol

One command per line (LF; CRLF accepted), one response line.

| Request | Response |
| --- | --- |
| `PING` | `OK pong=1` |
| `GET ALL` | `OK hostname=.. os=Linux kernel=.. cpu_cores=N cpu_usage_pct=F mem_total_kb=N mem_available_kb=N uptime_sec=N` |
| `GET CPU` | `OK cpu_cores=N cpu_usage_pct=F` (sampled from `/proc/stat` over 200 ms) |
| `GET MEMORY` | `OK mem_total_kb=N mem_available_kb=N` |
| `GET UPTIME` | `OK uptime_sec=N` |
| `GET HOSTNAME` | `OK hostname=NAME` |
| `QUIT` | `OK bye=1` then the server closes |
| `DEMO WAIT N` (1–5, server `--demo`) | `OK waited_sec=N` after N seconds |

Errors: `ERR code=<CODE> detail=<token>` with codes `BAD_COMMAND`,
`INVALID_ARGUMENT`, `REQUEST_TOO_LONG` (request > 256 bytes incl. LF, then
close), `TIMEOUT` (5 s for the first complete line, 10 s idle between
commands, then close), `INTERNAL_ERROR`, `SERVER_BUSY` (64 active children),
`DEMO_DISABLED`.

## Tests and evidence

All scripts are bash, accept `PORT=<n>` (default 9090) and write logs into
`docs/evidence/`.

| Script | What it checks | Evidence |
| --- | --- | --- |
| `tests/test_protocol.sh` | TC-01…TC-06: PING, GET *, 3 commands on one connection, QUIT, error codes, 256-byte limit, DEMO, `ldd` | `test_protocol.log`, `ldd.txt` |
| `tests/debug_matrix.sh` | TC-07: builds both modes, runs the 4 compile/run-time combinations, `strings` check | `debug_matrix.log` |
| `tests/concurrent_10.sh` | 10 parallel `DEMO WAIT 3` clients, `ps --ppid`, wall time, child PIDs | `concurrent_10.log`, `concurrent_10_ps.txt`, `concurrent_10_server.log` |
| `tests/test_robustness.sh --mode robust\|baseline` | RB-DEMO-01/02/03 (unknown command, idle client, zombies) | `robustness_robust.log`, `robustness_baseline.log` |
| `tests/capture_pcap.sh` | TC-08: tcpdump on `lo` during `GET ALL` + `PING`; needs root | `captures/loopback.pcap`, `pcap_summary.txt`, `pcap_ascii.txt` |

```bash
make && make baseline
tests/test_protocol.sh
tests/debug_matrix.sh          # leaves build/bin = debug build; run `make` to republish release
make
tests/concurrent_10.sh
tests/test_robustness.sh --mode robust
tests/test_robustness.sh --mode baseline
sudo -E tests/capture_pcap.sh  # or: SUDO_PASS=... tests/capture_pcap.sh
```

### Baseline vs robust

`make baseline` defines `BASELINE_MODE=1`, which enables three switches
(also available individually as `-DBASELINE_NO_VALIDATE=1`,
`-DBASELINE_NO_TIMEOUT=1`, `-DBASELINE_NO_REAP=1`):

| Switch | Robust build | Baseline build |
| --- | --- | --- |
| command validation | `ERR code=BAD_COMMAND`, connection kept | unknown command → connection closed silently |
| deadlines | 5 s first request / 10 s idle, `ERR code=TIMEOUT` | wait forever |
| child reaping | `SIGCHLD` → `waitpid(WNOHANG)` | no handler → zombies (`Z`) accumulate |

Memory-safety checks (request/response bounds, argument parsing) are
identical in both builds. The baseline binaries are for local experiments
only.

## Manual 10-client demo

```bash
./build/bin/server --port 9090 --debug --demo &
for i in $(seq 1 10); do ./build/bin/client --port 9090 --command "DEMO WAIT 3" & done
ps -o pid,ppid,stat,cmd --ppid $!   # within the 3 s window
wait
```
